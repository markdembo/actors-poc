Every failed call through an actor reference rejects with an ActorError.

#ActorError

class ActorError extends Error

PropertyTypeDescription
kind"action" | "validation" | "config" | "transport" | "timeout"What went wrong. Refer to the table below.
codestring | undefinedThe code property of the error the action threw, if it had one.
actor, key, methodstring | undefinedWhich call failed.
remoteNamestring | undefinedThe original error's name inside the actor, such as "TypeError".
remoteStackstring | undefinedThe stack trace from inside the actor.
retryablebooleantrue only when the platform marked a transport failure as safe to retry.

#Kinds

kindMeaningState committed?What to do
actionThe action threwNoExpected failures: map to a 4xx and use code
validationThe new state or return value was rejectedNoA bug: fix the action
configUnknown actor or action, missing binding, bad keyNo (never ran)A bug or a stale build: run actors generate
transportThe call failed in transit, for example an overloaded instanceUnknownRetry only if retryable and the action is idempotent
timeouttimeoutMs passedUnknown, usually yesDon't assume failure; read state or deduplicate

#Throwing errors with a code

You can also throw ActorError yourself inside an action. Its kind is preserved.
